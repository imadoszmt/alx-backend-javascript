# Node.js Basics Project

## Project Overview
A project focused on learning fundamental Node.js concepts including HTTP servers, Express.js, ES6, and basic file operations.

## Learning Objectives
- Node.js runtime basics
- Working with Node.js modules
- File operations in Node.js
- Command line and environment access using `process`
- Creating HTTP servers with Node.js and Express.js
- Advanced Express.js routing
- ES6 implementation with Babel-node
- Development workflow with Nodemon

## Technical Requirements
- **Development Environment:**
  - Editors: vi, vim, emacs, Visual Studio Code
  - Platform: Ubuntu 18.04 LTS
  - Node.js: Version 12.x.x

- **Code Standards:**
  - JavaScript files must use .js extension
  - All files must end with newline
  - Export format: `module.exports = myFunction;`
  - ESLint compliance required

- **Testing:**
  - Testing framework: Jest
  - Run tests: `npm run test`
  - Full project verification: `npm run full-test`

## Project Setup
1. Clone the repository
2. Run `npm install` to install dependencies
3. Verify setup with `npm run full-test`

## Provided Files
- database.csv: Sample data file with user information
- package.json: Project configuration
